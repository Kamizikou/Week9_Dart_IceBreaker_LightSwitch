## Description
This Dart application models a real-world **Light Switch** using Object-Oriented Programming (OOP) principles. It demonstrates class structure, constructors, encapsulation using private state variables, methods for behavior, and collection management via a `List` of objects.

---

## Features & Rubric Alignment

- **Class Definition:** Defines a `LightSwitch` class with public properties (`color`, `material`, `position`) and behavior methods (`flipUp()`, `flipDown()`, `displayStatus()`).
- **Constructor:** Sets initial object properties and default state upon instantiation.
- **Encapsulation:** Protects the switch's internal state using a private field (`_isOn`) accessible via a getter (`isOn`) and modified through explicit interaction methods.
- **List / Collection Usage:** Stores multiple `LightSwitch` instances inside a `List<LightSwitch>` to iterate through and manipulate object states.
